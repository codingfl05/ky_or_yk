행렬식·선형연립방정식·기본행렬 → 벡터공간의 공리·부분공간·기저·차원 → 고윳값과 대각화까지. 반드시 챙길 연결고리:

1. **행렬식 → rank → 가역성 → 고윳값**은 전부 가역행렬 동치조건 하나로 꿰어져 있다. 계산하기 쉬운 것 하나만 확인하면 나머지가 결정된다.
2. **선형독립·span·기저 판정**은 결국 연립방정식(RREF)으로 환원된다.
3. **부분공간·직교여공간**은 사영정리·내적공간에서 그대로 재사용된다.
4. **대칭행렬의 대각화 가능성**은 직교대각화, 이차형식, 스펙트럼 정리 전체를 관통한다.
5. **전이행렬 = 대각화의 $P$ = 기저변환**이라는 하나의 관점으로 SVD까지 연결된다.
