# 문제 카드 만들기 (Antigravity 규칙)

이 저장소는 편입 대비 복습 앱이다. 사용자가 보낸 문제 사진과 풀이·해설로 "문제 카드" 묶음을 만든다.
이 환경에는 터미널이 없다고 가정한다: 파일 작성 + 브랜치 커밋/push만 한다. 카드 변환(npm run ingest)은 Claude가 한다.

- 카드 작성 규칙(묶음 형식, 필드, 섹션, LaTeX, 단원 목록)은 @docs/gemini-instructions.md 의 "지시문" 블록을 그대로 따른다. 작업 전에 반드시 이 파일을 읽는다.
- 사용자 풀이 내용을 지어내거나 고치지 않는다. 불확실한 판독·의문점은 `## supplement`에 적는다.

## 작업 순서

1. 새 브랜치 `inbox/<YYYYMMDD-HHMM>`를 main에서 만든다.
2. 문제마다 카드를 써서 묶음 파일 하나로 저장한다: `inbox/bundle-<YYYYMMDD-HHMM>.md`
3. 문제 문장·그림이 담긴 사진을 `inbox/`에 저장한다. 파일명은 영어로 짧게: `p1.jpg`, `p2.png` ...
   - 묶음의 images에는 이 파일명을 정확히 쓴다. 풀이 사진은 저장하지 않는다.
   - 사진을 저장소에 파일로 저장할 수 없으면 images에는 "사진1", "사진2"처럼 적고, 사용자에게 "Claude에게 처리 요청할 때 문제 사진을 같은 순서로 첨부하세요"라고 알린다.
4. `inbox/` 안의 파일만 커밋해서 그 브랜치를 push한다.
5. 사용자에게 만든 문제 목록(제목·출처·난이도)과 supplement에 적은 의문점을 보고하고, "Claude에게 'inbox 브랜치 처리해'라고 하세요"라고 안내한다.

## 하지 말 것

- main 브랜치에 직접 커밋·push하지 않는다.
- inbox/ 밖의 파일(코드, 설정, CLAUDE.md, content/)을 만들거나 고치지 않는다.
- `related`는 비워 둔다 (Claude가 최종 검토 때 채운다).
