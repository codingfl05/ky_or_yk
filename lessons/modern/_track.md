현대물리는 낯선 결론이 많지만 출발점은 두 문장뿐이다. "빛의 속력은 누가 재도 같다"와 "입자는 파동이기도 하다". 이 레슨들은 그 두 문장에서 나머지가 어떻게 따라 나오는지를 처음부터 끝까지 같은 비유로 읽는다.

| 물리량 | 이 레슨에서의 비유 |
|---|---|
| 광속 $c$ | 누구에게나 똑같은 제한 속도 |
| 로런츠 인자 $\gamma$ | 두 관찰자 사이의 환율 |
| 고유 시간, 고유 길이 | 현지에서 직접 잰 값 (환전하기 전의 값) |
| 광자 | 에너지 $hf$짜리 동전 |
| 일함수 $\Phi$ | 금속을 빠져나오는 통행료 |
| 물질파, 파동함수 | 기타 줄의 떨림 |
| 확률 밀도 $\lvert\psi\rvert^2$ | 전자가 어디 있을지 알려 주는 일기예보 |
| 에너지 준위 | 사다리의 칸 |
| 양자수 | 전자의 주소 |
| 파울리 배타 원리 | 한 방에 한 명 |
| 에너지 띠 | 건물의 층 |
| 방사성 붕괴 | 매 순간 던지는 동전 |

통학길에는 레슨을 한 편씩 읽고, 책상에서 문제를 풀 때는 아래 도구 세 가지를 펴 놓는다. 수식 유도와 세부 조건은 각 레슨 끝의 공식 카드에 있다.
