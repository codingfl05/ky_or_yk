## 운동의 기술

| 상황 | 공식 |
|---|---|
| 정의 | $v = \dfrac{dx}{dt}$, $a = \dfrac{dv}{dt}$ |
| 등가속도 | $v = v_0 + at$<br>$\Delta x = v_0t + \frac{1}{2}at^2$ |
| | $\Delta x = \frac{1}{2}(v_0 + v)t$<br>$v^2 - v_0^2 = 2a\Delta x$ |
| 포물선 | $x = v_0\cos\theta\,t$<br>$y = v_0\sin\theta\,t - \frac{1}{2}gt^2$ |
| 최고 높이·도달 거리 | $H = \dfrac{v_0^2\sin^2\theta}{2g}$<br>$R = \dfrac{v_0^2\sin2\theta}{g}$ |
| 상대 속도 | $\mathbf{v}_{PA} = \mathbf{v}_{PB} + \mathbf{v}_{BA}$ |

## 힘

| 상황 | 공식 |
|---|---|
| 운동 법칙 | $\sum\mathbf{F} = m\mathbf{a} = \dfrac{d\mathbf{p}}{dt}$ |
| 작용·반작용 | $\mathbf{F}_{AB} = -\mathbf{F}_{BA}$ |
| 마찰 | $f_s \le \mu_sN$, $f_k = \mu_kN$ |
| 빗면 (마찰 없음) | $N = mg\cos\theta$, $a = g\sin\theta$ |
| 탄성력 | $F = -kx$ |
| 항력·종단 속도 | $D = \frac{1}{2}C\rho Av^2$<br>$v_t = \sqrt{\dfrac{2mg}{C\rho A}}$ |
| 연결된 물체 | $a = \dfrac{F_{\text{ext}}}{M}$ |
| 애트우드 | $a = \dfrac{(m_1 - m_2)g}{m_1 + m_2}$<br>$T = \dfrac{2m_1m_2g}{m_1+m_2}$ |
| 구심력 | $F = \dfrac{mv^2}{r} = mr\omega^2$ |
| 연직 원 꼭대기 | $v_{\min} = \sqrt{gr}$ |

## 일과 에너지

| 상황 | 공식 |
|---|---|
| 일 | $W = Fd\cos\theta = \int\mathbf{F}\cdot d\mathbf{r}$ |
| 일-운동 에너지 정리 | $W_{\text{net}} = \Delta K$<br>$K = \frac{1}{2}mv^2$ |
| 퍼텐셜 에너지 | $\Delta U = -W_c$, $F = -\dfrac{dU}{dx}$ |
| 중력·탄성 | $U = mgh$, $U = \frac{1}{2}kx^2$ |
| 역학적 에너지 보존 | $K_i + U_i = K_f + U_f$ |
| 비보존력 | $W_{\text{nc}} = \Delta K + \Delta U$ |
| 일률 | $P = \dfrac{dW}{dt} = Fv$ |

## 운동량과 충돌

| 상황 | 공식 |
|---|---|
| 운동량, 충격량 | $p = mv$, $J = \int F\,dt = \Delta p$ |
| 평균 힘 | $F_{\text{avg}} = \dfrac{\Delta p}{\Delta t}$ |
| 운동량 보존 | $m_1v_{1i} + m_2v_{2i} = m_1v_{1f} + m_2v_{2f}$ |
| 반발 계수 | $e = -\dfrac{v_{1f} - v_{2f}}{v_{1i} - v_{2i}}$ |
| 완전 비탄성 | $v_f = \dfrac{m_1v_1 + m_2v_2}{m_1 + m_2}$ |
| 탄성 (2 정지) | $v_{1f} = \dfrac{m_1 - m_2}{m_1+m_2}v_1$<br>$v_{2f} = \dfrac{2m_1}{m_1+m_2}v_1$ |
| 질량 중심 | $x_{\text{com}} = \dfrac{\sum m_ix_i}{M}$<br>$F_{\text{ext}} = Ma_{\text{com}}$ |

## 회전

| 상황 | 공식 |
|---|---|
| 대응 | $s = r\theta$<br>$v = r\omega$<br>$a_t = r\alpha$<br>$a_c = r\omega^2$ |
| 관성모멘트 | $I = \int r^2\,dm$ |
| 고리·원판·구·껍질 | $MR^2$<br>$\frac{1}{2}MR^2$<br>$\frac{2}{5}MR^2$<br>$\frac{2}{3}MR^2$ |
| 막대 (중심·끝) | $\frac{1}{12}ML^2$, $\frac{1}{3}ML^2$ |
| 평행축 정리 | $I = I_{\text{com}} + Md^2$ |
| 돌림힘 | $\tau = rF\sin\phi$, $\tau = I\alpha$ |
| 에너지·일률 | $K = \frac{1}{2}I\omega^2$<br>$W = \int\tau\,d\theta$<br>$P = \tau\omega$ |
| 구름 | $v = R\omega$<br>$K = \frac{1}{2}Mv^2 + \frac{1}{2}I\omega^2$ |
| 빗면 구름 | $a = \dfrac{g\sin\theta}{1 + I/MR^2}$ |
| 각운동량 | $L = I\omega = r_\perp mv$<br>$\tau = \dfrac{dL}{dt}$ |
| 보존 | $I_i\omega_i = I_f\omega_f$ |
| 세차 운동 | $\Omega = \dfrac{Mgr}{I\omega}$ |

## 평형

| 조건 | 공식 |
|---|---|
| 정적 평형 | $\sum F_x = 0$<br>$\sum F_y = 0$<br>$\sum\tau = 0$ |

> 돌림힘 기준점은 모르는 힘이 모인 곳으로.

## 중력

| 상황 | 공식 |
|---|---|
| 만유인력 | $F = \dfrac{Gm_1m_2}{r^2}$<br>$g = \dfrac{GM}{R^2}$ |
| 지구 내부 | $F = \dfrac{GMm}{R^3}r$ |
| 퍼텐셜 에너지 | $U = -\dfrac{GMm}{r}$ |
| 탈출 속력 | $v = \sqrt{\dfrac{2GM}{R}}$ |
| 원궤도 | $v = \sqrt{\dfrac{GM}{r}}$<br>$E = -\dfrac{GMm}{2r}$ |
| 케플러 3법칙 | $T^2 = \dfrac{4\pi^2}{GM}r^3$ |
| 케플러 2법칙 | $\dfrac{dA}{dt} = \dfrac{L}{2m}$ |

## 진동

| 상황 | 공식 |
|---|---|
| 위치 | $x = x_m\cos(\omega t + \phi)$ |
| 속도·가속도 | $v_{\max} = \omega x_m$, $a = -\omega^2x$ |
| 진동수 관계 | $\omega = 2\pi f = \dfrac{2\pi}{T}$ |
| 용수철 | $\omega = \sqrt{\dfrac{k}{m}}$ |
| 단진자·물리 진자 | $T = 2\pi\sqrt{\dfrac{L}{g}}$<br>$T = 2\pi\sqrt{\dfrac{I}{mgd}}$ |
| 비틀림 진자 | $T = 2\pi\sqrt{\dfrac{I}{\kappa}}$ |
| 에너지 | $E = \frac{1}{2}kx_m^2$ |

## 파동

| 상황 | 공식 |
|---|---|
| 진행파 | $y = y_m\sin(kx - \omega t)$ |
| 속력 | $v = f\lambda = \dfrac{\omega}{k}$, 줄 $v = \sqrt{\dfrac{T}{\mu}}$ |
| 간섭 | $y_m' = 2y_m\lvert\cos\frac{\phi}{2}\rvert$<br>$\phi = \dfrac{2\pi\Delta L}{\lambda}$ |
| 정상파 (양 끝 같은 종류) | $f_n = \dfrac{nv}{2L}$ |
| 정상파 (한쪽 닫힘) | $f_n = \dfrac{nv}{4L}$, $n$ 홀수 |
| 도플러 | $f' = f\dfrac{v \pm v_D}{v \mp v_S}$ |
| 일률·세기 | $P = \frac{1}{2}\mu v\omega^2y_m^2$<br>$I = \dfrac{P}{4\pi r^2}$ |

## 유체

| 상황 | 공식 |
|---|---|
| 압력 | $P = P_0 + \rho gh$ |
| 파스칼 | $\dfrac{F_i}{A_i} = \dfrac{F_o}{A_o}$ |
| 부력 | $F_b = \rho_fV_{\text{sub}}g$ |
| 연속 방정식 | $A_1v_1 = A_2v_2$ |
| 베르누이 | $P + \frac{1}{2}\rho v^2 + \rho gy = \text{const}$ |
| 토리첼리 | $v = \sqrt{2gh}$ |
