역학 전체를 하나의 흐름으로 읽는다. 힘이 원인이고, 가속도와 속도가 운동이고, 에너지와 운동량이 결과다. 회전, 진동, 파동, 유체는 이 흐름을 다른 옷으로 갈아입힌 것뿐이다.

| 물리량 | 이 레슨에서의 비유 |
|---|---|
| 알짜힘 | 운동을 바꾸는 유일한 원인 |
| 운동 에너지 | 지갑 (지금 쓸 수 있는 돈) |
| 퍼텐셜 에너지 | 통장 (저축) |
| 보존력 | 수수료 없는 은행 |
| 마찰 같은 비보존력 | 소매치기 (돈이 열로 새어 나감) |
| 운동량 | 끝까지 지켜지는 공동 재산 |
| 관성모멘트 | 회전의 무게 (축에서 멀수록 무거움) |
| 단진동 | 원운동의 그림자 |
| 압력 | 유체가 쓰는 힘의 단위 |

통학길에는 레슨을 한 편씩 읽고, 책상에서 문제를 풀 때는 아래 도구 세 가지를 펴 놓는다. 공식의 세부 조건과 유도는 각 레슨 끝의 공식 카드에 있다.
