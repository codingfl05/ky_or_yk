## 힘의 평형과 작용·반작용

| | 힘의 평형 | 작용·반작용 |
|---|---|---|
| 힘을 받는 물체 | 한 물체 | 서로 다른 두 물체 |
| 더하면 | 0 (평형일 때만) | 더할 수 없음 |
| 성립 | 가속하지 않을 때만 | 언제나 |
| 예 | 책의 무게와 수직항력 | 책의 무게와 책이 지구를 당기는 힘 |

> 엘리베이터가 가속하면 무게와 수직항력은 달라진다. 작용·반작용이라면 그럴 수 없다.

## 정지 마찰력과 운동 마찰력

| | 정지 마찰력 | 운동 마찰력 |
|---|---|---|
| 크기 | 필요한 만큼 (최대 $\mu_sN$) | 항상 $\mu_kN$ |
| 언제 | 접촉면이 미끄러지지 않을 때 | 미끄러질 때 |
| 일 | 하지 않는다 (구름 운동 포함) | 음의 일, 열로 손실 |

> "마찰력 = $\mu N$"은 미끄러질 때만이다. 정지해 있으면 힘의 평형으로 구한다.

## 일과 충격량

| | 일 | 충격량 |
|---|---|---|
| 정의 | $\int F\,dx$ (거리로 쌓기) | $\int F\,dt$ (시간으로 쌓기) |
| 바뀌는 것 | 운동 에너지 (스칼라) | 운동량 (벡터) |
| 그래프 | $F$–$x$ 넓이 | $F$–$t$ 넓이 |
| 잘 맞는 상황 | 거리가 분명할 때 | 충돌처럼 시간이 분명할 때 |

## 운동량 보존과 에너지 보존

| | 운동량 보존 | 역학적 에너지 보존 |
|---|---|---|
| 조건 | 계에 외력이 없다 | 비보존력이 일을 안 한다 |
| 충돌에서 | 항상 성립 (충돌 순간) | 탄성 충돌만 |
| 종류 | 벡터 (성분마다) | 스칼라 |

> 충돌 뒤에 운동이 이어지면: 충돌 순간은 운동량, 그 뒤는 에너지.

## 탄성, 비탄성, 완전 비탄성

| | 탄성 | 비탄성 | 완전 비탄성 |
|---|---|---|---|
| 운동량 | 보존 | 보존 | 보존 |
| 운동 에너지 | 보존 | 일부 손실 | 가장 많이 손실 |
| 반발 계수 | $1$ | $0<e<1$ | $0$ |
| 충돌 후 | 상대 속도 뒤집힘 | | 같이 움직임 |

## 보존력과 비보존력

| | 보존력 | 비보존력 |
|---|---|---|
| 예 | 중력, 탄성력, 전기력 | 마찰, 항력, 외력 |
| 한 일 | 경로 무관, 닫힌 경로 0 | 경로에 따라 다름 |
| 퍼텐셜 에너지 | 있음 ($\Delta U = -W$) | 없음 |
| 역학적 에너지 | 보존 | 그 일만큼 변함 |

## mgh와 −GMm/r

| | $mgh$ | $-\dfrac{GMm}{r}$ |
|---|---|---|
| 기준점 | 지표면 ($U = 0$) | 무한대 ($U = 0$) |
| 쓰는 때 | 높이 ≪ 지구 반지름 | 위성, 탈출, 큰 높이 |
| 힘 | $mg$ (일정) | $\dfrac{GMm}{r^2}$ |

> 같은 것을 다른 기준으로 본 것이다. 지표 근처에서 $-\frac{GMm}{r}$의 차이를 계산하면 $mgh$가 나온다.

## 구심 가속도와 접선 가속도

| | 구심 가속도 | 접선 가속도 |
|---|---|---|
| 크기 | $\dfrac{v^2}{r} = r\omega^2$ | $r\alpha$ |
| 방향 | 원의 중심 | 원의 접선 |
| 하는 일 | 속도의 방향을 바꿈 | 속력을 바꿈 |
| 만드는 것 | 구심력 (중심 방향 알짜힘) | 돌림힘 |
| 등속 원운동에서 | 있음 | 0 |

## 직선 운동과 회전 운동

| 직선 | 회전 |
|---|---|
| $x$, $v$, $a$ | $\theta$, $\omega$, $\alpha$ |
| $m$ | $I = \int r^2\,dm$ |
| $F = ma$ | $\tau = I\alpha$ |
| $\frac{1}{2}mv^2$ | $\frac{1}{2}I\omega^2$ |
| $W = \int F\,dx$ | $W = \int\tau\,d\theta$ |
| $P = Fv$ | $P = \tau\omega$ |
| $p = mv$ | $L = I\omega$ |
| 운동량 보존 (외력 0) | 각운동량 보존 (외부 돌림힘 0) |

## 미끄러지는 물체와 구르는 물체

| | 미끄러짐 (마찰 없음) | 구름 (미끄러짐 없음) |
|---|---|---|
| 빗면 가속도 | $g\sin\theta$ | $\dfrac{g\sin\theta}{1 + I/MR^2}$ |
| 바닥 속력 | $\sqrt{2gh}$ | $\sqrt{\dfrac{2gh}{1 + I/MR^2}}$ |
| 에너지 | 전부 병진 | 병진 + 회전으로 나뉨 |
| 마찰력 | 없음 | 정지 마찰 (일 안 함) |

## 용수철 진자와 단진자

| | 용수철 진자 | 단진자 |
|---|---|---|
| 주기 | $2\pi\sqrt{\dfrac{m}{k}}$ | $2\pi\sqrt{\dfrac{L}{g}}$ |
| 질량을 바꾸면 | 바뀜 | 그대로 |
| 중력이 바뀌면 (달, 엘리베이터) | 그대로 (평형점만 이동) | 바뀜 |
| 진폭을 바꾸면 | 그대로 | 그대로 (작은 각) |

## 파동의 속력과 매질 한 점의 속력

| | 파동의 속력 | 매질 한 점의 속도 |
|---|---|---|
| 식 | $v = f\lambda = \dfrac{\omega}{k}$ | $u = \dfrac{\partial y}{\partial t}$, 최대 $\omega y_m$ |
| 방향 | 진행 방향 | 진동 방향 (횡파면 수직) |
| 정하는 것 | 매질 (장력, 밀도) | 진폭, 진동수 |

## 양 끝 같은 종류와 한쪽 닫힘

| | 양 끝 고정 / 양 끝 열림 | 한쪽만 닫힘 |
|---|---|---|
| 끝 | 마디-마디 / 배-배 | 마디-배 |
| 파장 | $\dfrac{2L}{n}$ | $\dfrac{4L}{n}$ |
| 배음 | 모든 $n$ | 홀수 $n$만 |
| 기본 진동수 | $\dfrac{v}{2L}$ | $\dfrac{v}{4L}$ |

## 정지 유체와 흐르는 유체

| | 정지 | 흐름 |
|---|---|---|
| 압력 | $P_0 + \rho gh$ (깊이만) | 베르누이 (속력·높이) |
| 같은 높이 | 압력 같음 | 빠른 곳이 압력 낮음 |
| 짝이 되는 역학 | 힘의 평형 | 에너지 보존 |
