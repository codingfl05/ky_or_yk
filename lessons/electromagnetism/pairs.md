## 전기장 E와 전위 V

| | 전기장 $E$ | 전위 $V$ |
|---|---|---|
| 비유 | 땅의 경사 | 땅의 높이 |
| 종류 | 벡터 (성분, 상쇄를 따진다) | 스칼라 (부호 붙여 그냥 더한다) |
| 점전하 | $\dfrac{kq}{r^2}$ | $\dfrac{kq}{r}$ |
| 받는 전하를 곱하면 | 힘 $F = qE$ | 에너지 $U = qV$ |
| 서로의 관계 | $E = -\dfrac{dV}{dr}$ | $\Delta V = -\displaystyle\int\mathbf{E}\cdot d\mathbf{s}$ |

> 평평하다고 낮은 것이 아니다. $E = 0$이어도 $V \neq 0$일 수 있고 (같은 전하 둘의 한가운데), $V = 0$이어도 $E \neq 0$일 수 있다 ($+q$와 $-q$의 한가운데).

## 선속이 0인 것과 전기장이 0인 것

| 말 | 뜻 |
|---|---|
| 닫힌 면의 알짜 선속이 0 | 면 안의 알짜 전하가 0. 들어온 만큼 나간다 |
| 면 위의 전기장이 0 | 훨씬 강한 조건. 선속이 0이어도 보통은 성립하지 않는다 |

> 가우스 면 안에 전하가 없어도, 밖의 전하가 만든 전기장은 면을 지나간다.

## 부도체 판과 도체 표면

| | 얇은 부도체 판 | 도체 표면 바로 밖 |
|---|---|---|
| 전기장 | $\dfrac{\sigma}{2\varepsilon_0}$ | $\dfrac{\sigma}{\varepsilon_0}$ |
| 가우스 면의 뚜껑 | 양쪽 두 장으로 나감 ($2EA$) | 안쪽은 $E=0$, 바깥 한 장만 ($EA$) |

> 같은 전하가 양쪽으로 나뉘어 나가느냐, 한쪽으로 몰려 나가느냐의 차이다. 반대 부호로 대전된 평행판 사이는 두 판의 전기장이 더해져 $\dfrac{\sigma}{\varepsilon_0}$, 바깥은 지워져 $0$.

## 구껍질, 속이 찬 부도체 구, 도체 구

| | 안쪽 ($r < R$)의 $E$ | 바깥 ($r > R$)의 $E$ | 안쪽의 $V$ |
|---|---|---|---|
| 구껍질 | $0$ | $\dfrac{kq}{r^2}$ | $\dfrac{kq}{R}$로 일정 |
| 균일한 부도체 구 | $\dfrac{kq}{R^3}r$ | $\dfrac{kq}{r^2}$ | 중심으로 갈수록 더 높아짐 |
| 도체 구 | $0$ | $\dfrac{kq}{r^2}$ | $\dfrac{kq}{R}$로 일정 |

> 바깥에서는 셋 다 점전하다. 차이는 안쪽에 전하가 있느냐뿐이다. 도체 구는 전하가 전부 표면에 있으니 구껍질과 같다.

## 거리에 따라 약해지는 빠르기

| 만드는 것 | 장의 세기 | 이유 |
|---|---|---|
| 점전하 | $\dfrac{1}{r^2}$ | 구면 $4\pi r^2$에 퍼짐 |
| 무한 직선 전하, 무한 직선 전류 | $\dfrac{1}{r}$ | 원기둥 옆면(둘레 $2\pi r$)에 퍼짐 |
| 무한 평면 | 일정 | 퍼질 곳이 없음 |
| 쌍극자 (전기·자기 모두) | $\dfrac{1}{r^3}$ | 알짜가 0이라 멀리서 서로 지움 |
| 솔레노이드 내부 | 일정 | 자기장을 안에 가둠 |

## 가우스 법칙과 앙페르 법칙

| | 가우스 | 앙페르 |
|---|---|---|
| 식 | $\varepsilon_0\displaystyle\oint\mathbf{E}\cdot d\mathbf{A} = q_{\text{enc}}$ | $\displaystyle\oint\mathbf{B}\cdot d\mathbf{s} = \mu_0 i_{\text{enc}}$ |
| 잡는 것 | 닫힌 면 | 닫힌 고리 |
| 세는 것 | 면 안의 전하 | 고리를 꿰뚫는 전류 |
| 곱하는 것 | 뚫고 나가는 넓이 | 따라 도는 길이 |
| 쓸 수 있을 때 | 구·원통·평면 대칭 | 긴 직선·솔레노이드·토로이드 |

> 둘 다 "법칙은 항상 참, 계산에 쓸모 있는 것은 대칭일 때"다. 대칭이 없으면 쪼개서 더한다 (쿨롱, 비오-사바르).

## 쿨롱 법칙과 비오-사바르 법칙

| | 전기장 조각 | 자기장 조각 |
|---|---|---|
| 만드는 조각 | $dq$ | $i\,d\mathbf{s}$ |
| 크기 | $\dfrac{1}{4\pi\varepsilon_0}\dfrac{dq}{r^2}$ | $\dfrac{\mu_0}{4\pi}\dfrac{i\,ds\,\sin\theta}{r^2}$ |
| 방향 | 조각에서 멀어지는 쪽 | 조각을 감싸는 쪽 (오른손) |
| 0이 되는 곳 | 없음 | 조각의 연장선 위 ($\sin\theta = 0$) |

## 전기력과 자기력

| | 전기력 $q\mathbf{E}$ | 자기력 $q\mathbf{v}\times\mathbf{B}$ |
|---|---|---|
| 정지한 전하 | 받는다 | 받지 않는다 |
| 방향 | 장과 나란히 | 속도와 장 모두에 수직 |
| 일 | 한다 (속력이 변함) | 하지 않는다 (방향만 변함) |
| 균일한 장에서의 운동 | 포물선 | 원 (또는 나선) |

## 같은 것끼리 밀까 당길까

| | 같은 부호·같은 방향 | 다른 부호·반대 방향 |
|---|---|---|
| 전하 | 민다 | 당긴다 |
| 평행한 전류 | 당긴다 | 민다 |

> 전류는 전하와 반대다. 같은 방향으로 흐르는 두 전류는 서로 끌린다.

## 전기 쌍극자와 자기 쌍극자

| | 전기 쌍극자 | 자기 쌍극자 (전류 고리) |
|---|---|---|
| 모멘트 | $p = qd$ (−에서 + 방향) | $\mu = NiA$ (오른손 엄지) |
| 돌림힘 | $\boldsymbol\tau = \mathbf{p}\times\mathbf{E}$ | $\boldsymbol\tau = \boldsymbol\mu\times\mathbf{B}$ |
| 에너지 | $U = -\mathbf{p}\cdot\mathbf{E}$ | $U = -\boldsymbol\mu\cdot\mathbf{B}$ |
| 축 위 먼 곳의 장 | $\dfrac{1}{2\pi\varepsilon_0}\dfrac{p}{z^3}$ | $\dfrac{\mu_0}{2\pi}\dfrac{\mu}{z^3}$ |

> 둘 다 장과 나란히 서려고 돈다. 나란할 때 에너지가 가장 낮다.

## 저항의 합성과 축전기의 합성

| | 직렬 | 병렬 |
|---|---|---|
| 같은 것 | 전류 (축전기는 전하) | 전압 |
| 저항 ($R \propto \frac{L}{A}$) | $R_1 + R_2$ | $\dfrac{1}{R_1} + \dfrac{1}{R_2}$의 역수 |
| 축전기 ($C \propto \frac{A}{d}$) | $\dfrac{1}{C_1} + \dfrac{1}{C_2}$의 역수 | $C_1 + C_2$ |

> 직렬은 길이(간격)가 늘어나는 것, 병렬은 넓이가 늘어나는 것이다. 모양 공식에 넣어 보면 어느 쪽을 더하는지 바로 나온다.

## 유전체: 전하 고정과 전압 고정

| | 배터리 분리 ($q$ 고정) | 배터리 연결 ($V$ 고정) |
|---|---|---|
| $C$ | $\kappa$배 | $\kappa$배 |
| $q$ | 그대로 | $\kappa$배 |
| $V$, $E$ | $\dfrac{1}{\kappa}$배 | 그대로 |
| $U$ | $\dfrac{1}{\kappa}$배 | $\kappa$배 |

> 판 간격을 바꾸는 문제도 똑같다. 무엇이 고정인지부터 정한다.

## 전력 식 세 가지

| 식 | 쓰는 때 | 결과 |
|---|---|---|
| $P = i^2R$ | 전류가 같은 것끼리 (직렬) | 저항이 클수록 큼 |
| $P = \dfrac{V^2}{R}$ | 전압이 같은 것끼리 (병렬) | 저항이 작을수록 큼 |
| $P = iV$ | 전원이 공급하는 전력 | |

## 축전기와 코일

| | 축전기 (물탱크) | 코일 (물레방아) |
|---|---|---|
| 갑자기 못 변하는 것 | 전압 | 전류 |
| 먹는 전압 | $\dfrac{q}{C}$ | $L\dfrac{di}{dt}$ |
| 저장 에너지 | $\dfrac{q^2}{2C} = \dfrac{1}{2}CV^2$ | $\dfrac{1}{2}Li^2$ |
| 에너지 밀도 | $\dfrac{1}{2}\varepsilon_0E^2$ | $\dfrac{B^2}{2\mu_0}$ |
| 스위치 직후 | 도선 (비어 있을 때) | 끊긴 선 |
| 한참 뒤 | 끊긴 선 | 도선 |
| 시간 상수 | $RC$ | $\dfrac{L}{R}$ |
| 교류에서 방해 | $X_C = \dfrac{1}{\omega C}$ (느릴수록 막음) | $X_L = \omega L$ (빠를수록 막음) |
| 교류에서 전류 | 전압보다 $90^\circ$ 먼저 | 전압보다 $90^\circ$ 늦게 |

> 모든 줄이 정반대다. 한쪽을 알면 다른 쪽은 뒤집으면 된다.

## 패러데이 법칙과 렌츠 법칙

| | 패러데이 | 렌츠 |
|---|---|---|
| 알려 주는 것 | 기전력의 크기 | 기전력의 방향 |
| 내용 | 선속이 변하는 빠르기 | 변화를 방해하는 쪽 |

> 유도 자기장이 반대하는 것은 원래 자기장이 아니라 "변화"다. 선속이 줄어들고 있으면 유도 자기장은 원래 자기장과 같은 방향이다.

## 용수철 진동과 LC 진동

| 용수철 | LC 회로 |
|---|---|
| 위치 $x$ | 전하 $q$ |
| 속도 $v$ | 전류 $i$ |
| $k$ | $\dfrac{1}{C}$ |
| $m$ | $L$ |
| $\dfrac{1}{2}kx^2$ | $\dfrac{q^2}{2C}$ |
