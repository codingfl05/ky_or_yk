id: electromagnetism
title: "전자기학"
subtitle: "높이와 물로 읽는 전기, 소용돌이로 읽는 자기"
---

공식을 외우기 전에 "왜 그렇게 생겼는지"를 하나의 그림으로 먼저 잡는다. 이 레슨들은 처음부터 끝까지 같은 비유를 쓴다.

| 물리량 | 이 레슨에서의 비유 |
|---|---|
| 전하 | 땅을 솟게 하거나(+) 꺼지게 하는(−) 것 |
| 전위 $V$ | 땅의 높이 |
| 전기장 $E$ | 땅의 경사 (내리막 방향) |
| 전류 $i$ | 흐르는 물 |
| 전원 | 물을 퍼 올리는 펌프 |
| 저항 | 좁고 긴 수로 |
| 축전기 | 물탱크 |
| 코일 | 무거운 물레방아 (흐름의 관성) |
| 자기장 $B$ | 전류를 감싸는 소용돌이 |

통학길에는 레슨을 한 편씩 읽고, 책상에서 문제를 풀 때는 아래 도구 세 가지를 펴 놓는다. 수식 유도와 세부 조건은 각 레슨 끝의 공식 카드에 있다.
